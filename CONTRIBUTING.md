# Руководство по вкладу

Спасибо за интерес к проекту! Это руководство поможет вам внести свой вклад.

## Форматирование Markdown

### Структура файла

Каждый Markdown-файл должен содержать YAML-метаданные:

```markdown
---
title: "Название текста"
description: "Краткое описание содержания"
keywords: [ключевое, слово1, слово2]
source: /оригинальный/путь.html
converted: 2026-07-27T11:11:06.587086
---

# Заголовок текста

Содержимое...
```

### Правила оформления

1. **Заголовки**
   - Используйте `#` для основного заголовка
   - Используйте `##` для разделов
   - Максимум 3 уровня вложенности

2. **Абзацы**
   - Пустая строка между абзацами
   - Красная строка (отступ) для первого предложения не требуется в HTML

3. **Списки**
   - Маркированные списки: `-` или `*`
   - Нумерованные списки: `1.` и т.д.
   - Вложенность: 2 пробела перед маркером

4. **Форматирование текста**
   - Жирный: `**текст**`
   - Курсив: `*текст*`
   - Ссылки: `[текст](url)`

5. **Таблицы**
   - Используйте `|` для столбцов
   - Вторая строка с `|---|` обязательна

### Пример

```markdown
## Название раздела

Первый абзац раздела с подробным описанием.

Второй абзац с новой мыслью.

### Подраздел

- Элемент списка 1
- Элемент списка 2
  - Вложенный элемент

| Столбец 1 | Столбец 2 |
|-----------|-----------|
| Данные    | Данные    |
```

## Добавление нового текста

1. Создайте файл в соответствующем разделе `/content/`:
   - `/content/nag-hammadi/` — для текстов Наг-Хаммади
   - `/content/apocrypha/new/` — для новозаветных апокрифов
   - `/content/apocrypha/old/` — для ветхозаветных апокрифов
   - `/content/gnostic/` — для гностических текстов
   - `/content/kumran/` — для кумранских текстов
   - `/content/hermetic/` — для герметических трактатов
   - `/content/study/` — для исследований

2. Назовите файл транслитерированным русским названием:
   - `Протоевангелие от Иакова` → `protoevangelie-ot-iakova.md`
   - Используйте строчные буквы и дефисы

3. Заполните метаданные:
   - `title`: Полное название текста
   - `description`: Краткое описание (1-2 предложения)
   - `keywords`: Ключевые слова для поиска

## Проверка

Перед отправкой pull request:

1. Проверьте синтаксис YAML-метаданных
2. Убедитесь, что файл открывается как Markdown
3. Проверьте ссылки и форматирование
