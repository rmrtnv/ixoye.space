# Руководство по вкладу

Спасибо за интерес к проекту! Это руководство поможет вам внести свой вклад.

## Как устроен сайт

Опубликованный сайт — это набор статических HTML-страниц в разделах:
`nag-hammadi/`, `apocrypha-new/`, `apocrypha-old/`, `gnostic/`, `hermetic/`,
`kumran/`, `study/`, а также служебных страниц в корне.

**Источник правды — HTML-файлы в этих каталогах.** Каталог `content/` с
Markdown-черновиками устарел и сайтом не используется (см. `content/README.md`).

Оформление вынесено в один файл `src/styles/main.css`, который подключается
абсолютным путём `/src/styles/main.css`. Не добавляйте в страницы инлайновые
стили и не подключайте свои таблицы стилей.

## Добавление нового текста

1. **Выберите раздел** и создайте в нём файл с транслитерированным названием,
   строчными буквами и дефисами: `Протоевангелие от Иакова` → `protoevangelie-ot-iakova.html`.

2. **Скопируйте шаблон** (замените заголовок, описание и текст):

   ```html
   <!DOCTYPE html>
   <html lang="ru">
   <head>
   <meta charset="UTF-8">
   <meta name="viewport" content="width=device-width, initial-scale=1">
   <title>Название текста — Библиотека Наг-Хаммади — Русская Апокрифическая Студия</title>
   <meta name="description" content="Краткое описание содержания">
   <link rel="stylesheet" href="/src/styles/main.css">
   </head>
   <body>
   <main class="container content-block">
   <p><a href="/nag-hammadi/index.html">← Библиотека Наг-Хаммади</a></p>
   <h1>Название текста</h1>
   <p>Первый абзац…</p>
   </main>
   </body>
   </html>
   ```

3. **Добавьте ссылку** на новый текст в индексной странице раздела
   (`index.html`) рядом с остальными текстами.

4. **Проверьте сборку:**

   ```sh
   npm run maintenance
   ```

   Команда проверит внутренние ссылки и обновит `sitemap.xml` и `search-index.json`.

## Правила оформления текста

- один `<h1>` на страницу (название текста), далее `<h2>`/`<h3>`;
- абзацы — `<p>`, выделение — `<em>`/`<strong>`;
- цитаты — `<blockquote>`, стихи/нумерация — `<sup>` или отдельные абзацы;
- ссылки относительные (внутри сайта) или `https://` (наружу);
- изображения — с обязательным `alt`;
- не используйте устаревшие теги `<font>`, `<center>` для новой вёрстки.

## Метаданные

- `title` — уникальный, по схеме «Название — Раздел — Русская Апокрифическая Студия»;
- `description` — 1–2 предложения, отличающиеся от других страниц.

## Перед отправкой

1. `npm run check-links` — не должно быть битых ссылок.
2. Проверьте страницу в браузере (широкий экран и телефон).
3. Убедитесь, что кодировка UTF-8 и файл открывается как HTML.

## Git-хуки

Чтобы проверки запускались автоматически перед коммитом:

```sh
git config core.hooksPath .githooks
```
