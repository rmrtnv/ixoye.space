# ixoye.space — Русская Апокрифическая Студия

Научный сайт, представляющий собой крупнейшее собрание раннехристианских и относящихся к ним текстов на русском языке.

## О проекте

Сайт создан для:
- Студентов теологических факультетов
- Учёных-религиоведов
- Широкого круга читателей, интересующихся историей раннего христианства

## Технические особенности

### Progressive Web App (PWA)

Сайт работает как прогрессивное веб-приложение:

- **Офлайн-режим**: Все тексты доступны без интернета
- **Установка**: Можно установить на домашний экран мобильного устройства
- **Автокэширование**: При первом запуске из PWA на WiFi сайт автоматически сохраняет все тексты для офлайн-чтения
- **Быстрая загрузка**: Контент кэшируется для мгновенного доступа

## Разработка

### Требования

- Node.js 18+
- npm

### Установка

```bash
npm install
```

### Запуск

```bash
npm run dev
```

Откройте http://localhost:3000 в браузере.

### Обновление кэша Service Worker

Service Worker использует версию из `package.json` для именования кэшей. При каждом деплое:

1. Увеличьте версию в `package.json`
2. Запушьте изменения — GitHub Pages развернет новую версию
3. Пользователи автоматически получат обновлённый кэш

### Обновление списка офлайн-страниц

`precache-manifest.json` обновляется автоматически через Git pre-commit hook при каждом коммите, если вы добавили или удалили HTML-файлы.

**Настройка hook (один раз после клонирования):**

```bash
cp .githooks/pre-commit .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

После настройки hook работает автоматически. При коммите изменений в HTML-файлов манифест перегенерируется и добавляется в тот же коммит.

Ручной способ (если hook не настроен):

```bash
npm run generate-precache
git add precache-manifest.json
git commit -m "Update precache manifest"
```

### Структура Markdown-файлов

Каждый текст в `/content/` содержит YAML-метаданные:

```yaml
---
title: "Название текста"
description: "Краткое описание"
keywords: [ключевые, слова]
source: /оригинальный/путь.html
converted: 2026-07-27T11:11:06.587086
---

# Содержимое текста
```
