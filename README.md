# ixoye.space — Русская Апокрифическая Студия

Научный сайт, представляющий собой крупнейшее собрание раннехристианских и относящихся к ним текстов на русском языке.

## О проекте

Сайт создан для:
- Студентов теологических факультетов
- Учёных-религиоведов
- Широкого круга читателей, интересующихся историей раннего христианства

## Содержание

### Коллекции текстов

| Раздел | Описание |
|--------|----------|
| **Наг-Хаммади** | Библиотека Наг-Хаммади — собрание гностических текстов |
| **Новозаветные апокрифы** | Апокрифические евангелия, деяния, послания |
| **Ветхозаветные апокрифы** | Апокрифические тексты Ветхого Завета |
| **Гностицизм** | Гностические трактаты и исследования |
| **Герметизм** | Герметические трактаты |
| **Свитки Иудейской пустыни** | Кумранские тексты (Мёртвое море) |
| **Исследования** | Научные статьи и комментарии |
