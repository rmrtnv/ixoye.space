# ixoye.space — Русская Апокрифическая Студия

Научный сайт, представляющий собой крупнейшее собрание раннехристианских и относящихся к ним текстов на русском языке.

## О проекте

Сайт создан для:

- студентов теологических факультетов;
- учёных-религоведов;
- широкого круга читателей, интересующихся историей раннего христианства.

- `index.html` — главная с новостями;
- `about.html` — история студии;
- `poisk.html` — полнотекстовый поиск по сайту;
- `search-index.json` — индекс для поиска (генерируется).

## Технические особенности

- **Чистый статический сайт.** Никаких сборщиков и серверного кода — опубликованные HTML-страницы лежат в репозитории как есть.
- **Хостинг:** GitHub Pages, пользовательский домен `ixoye.space` (файл `CNAME`).
- **Кодировка:** UTF-8 во всех файлах.
- **Единая тема оформления:** `src/styles/main.css` — современный адаптивный CSS (переменные, тёмная типографика, печать, поддержка мобильных). Подключается абсолютным путём `/src/styles/main.css`, поэтому работает из любого раздела.
- **HTML как единственный источник правды.** Тексты книг хранятся в HTML. Каталог `content/` — это устаревшая черновая конвертация в Markdown, сохранённая только для истории (см. `content/README.md`).
- **Проверки:** сквозная проверка внутренних ссылок и генерация `sitemap.xml` / `search-index.json` выполняются скриптами из `scripts/`.
- **GitHub Pages:** включён `.nojekyll` (страницы отдаются как есть). Существующие адреса сохраняются: переименование каталогов и `.shtml`-файлов не выполняется, чтобы не ломать внешние ссылки и поисковую выдачу.

## Локальный запуск

Сайт — это статический HTML, сборка не требуется. Для локального просмотра
достаточно Node.js (встроенный сервер, без зависимостей):

```sh
npm run dev      # http://localhost:3000
npm run preview  # http://localhost:4000 (другой порт)
```

Сервер (`scripts/dev-server.mjs`) ведёт себя как GitHub Pages: страницы с
`.html` отдаются напрямую (без перезаписи URL), `/раздел` переадресуется на
`/раздел/`. Поэтому все относительные ссылки сайта, включая ссылки на тексты,
работают так же, как в продакшене.

### Офлайн-чтение и service worker: когда нужен HTTPS

Service worker (офлайн-режим, страница `/offline.html`) работает только в
защищённом контексте. Для обычной локальной проверки на компьютере HTTPS **не
нужен**: браузеры считают `http://localhost` защищённым контекстом, поэтому
`npm run dev` достаточно.

HTTPS обязателен для проверки **с другого устройства** (например, телефона по
локальной сети) — по `http://192.168.x.x:3000` service worker не запускается:

```sh
node scripts/dev-server.mjs --https --port 3443
```

При первом запуске сервер сам создаст самоподписанный сертификат в
`.dev-certs/` (SAN: `localhost` + адреса вашей локальной сети) и напечатает
инструкции, как ему довериться: одна команда для macOS (`security
add-trusted-cert`), установка профиля с включением «полного доверия» на iOS,
установка CA на Android. После доверия перезапустите браузер и открывайте сайт
по адресу `https://<ip-машины>:3443`. Продакшен (GitHub Pages) всегда
работает по HTTPS, и там офлайн-режим доступен без каких-либо настроек.

## Обслуживание

Вспомогательные скрипты (Node.js, без зависимостей):

| Команда | Назначение |
|---------|-----------|
| `npm run check-links` | Проверка всех внутренних ссылок |
| `npm run sitemap` | Перегенерация `sitemap.xml` |
| `npm run search-index` | Перегенерация `search-index.json` |
| `npm run maintenance` | Всё вместе: ссылки + sitemap + поисковый индекс |

Скрипты `scripts/repair-html.mjs` и `scripts/create-restoration-stubs.mjs` использовались при миграции архива и остаются как воспроизводимые инструменты нормализации.

### Git-хуки

Автопроверки перед коммитом включаются один раз:

```sh
git config core.hooksPath .githooks
```
