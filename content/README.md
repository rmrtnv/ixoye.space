# Архив черновой конвертации (не используется сайтом)

Каталог `content/` содержит **устаревшую и неполную** конвертацию HTML-страниц в Markdown,
выполненную в 2026 году при экспериментальной миграции на генератор сайтов.

⚠️ **Это не источник правды и не часть опубликованного сайта.**

- Конвертация пострадала при извлечении: заголовки слились с абзацами, часть
  форматирования и разметки потеряна.
- Только у ~210 из 381 файла есть соответствующий HTML-двойник; многие пути в
  метаданных (`source:`) указывают на старые имена каталогов, которых больше нет.
- Ни один скрипт сайта не читает эти файлы. GitHub Pages их не публикует.

**Редактировать тексты нужно в HTML** — см. [CONTRIBUTING.md](../CONTRIBUTING.md).
Каталог сохранён только для истории; при желании его можно удалить.
